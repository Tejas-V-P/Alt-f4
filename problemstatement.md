Placement Preparation Portal
Duration
2 Hours
Team Size
4-3 Students

Problem Statement
Preparing for campus placements involves keeping track of multiple company applications, interview rounds, preparation resources, and application status. Students often rely on spreadsheets or notes, making it difficult to stay organized.
Your challenge is to build a Placement Preparation Portal that helps students efficiently manage their placement journey in one place. The application should provide an easy way to track company applications, monitor progress, and organize preparation resources.
The goal is to create a functional, user-friendly, and responsive web application within the given time.

Minimum Requirements (Mandatory)
1. User Authentication
User Registration
User Login
JWT Authentication
Protected Dashboard

2. Dashboard
After login, the dashboard should display:
Total Companies Applied
Total Active Applications
Total Offers (or Selected)
Total Rejected Applications

3. Company Application Tracker (CRUD)
Users should be able to:
Add a Company
View All Companies
Update Company Details
Delete Company
Each company should contain:
Company Name
Role
Application Date
Status
Status can be one of:
Applied
Online Assessment
Technical Interview
HR Interview
Selected
Rejected

4. Search & Filter
Users should be able to:
Search by Company Name
Filter by Application Status

5. Preparation Resources
Users can add useful preparation resources.
Each resource should include:
Title
Category
Link
Categories:
DSA
Aptitude
Resume
Interview Experience
Core Subjects

Do's
Complete the mandatory requirements first.
Build a clean and intuitive UI.
Validate user inputs.
Follow REST API conventions.
Keep your code modular and organized.
Test the application before submission.

Don'ts
Do not copy existing placement management projects.
Do not expose API keys or sensitive credentials.
Do not use hardcoded data in place of database operations.
Do not leave broken routes or incomplete CRUD functionality.
Do not compromise security (e.g., storing passwords in plain text).
